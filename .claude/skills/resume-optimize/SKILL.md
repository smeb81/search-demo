# 简历优化 Skill

## 概述

此 skill 用于优化中文简历的内容和格式，帮助用户提升简历质量，增加面试机会。

## 触发时机

当用户提出以下需求时，必须使用此 skill：
- 简历优化 / 简历修改 / 简历润色
- 简历诊断 / 简历评估 / 简历打分
- 简历建议 / 简历指导 / 简历咨询
- 简历怎么写 / 简历怎么改
- 简历问题 / 简历审查 / 简历检查
- 简历完善 / 简历提升 / 简历辅导

## 输入方式

支持以下文件格式的简历输入：
- **PDF 文件**：使用 pdf skill 提取文本内容
- **Word 文件（.docx）**：使用 docx skill 读取内容
- **Markdown 文件（.md）**：直接读取文本
- **纯文本**：直接处理文本内容

## 输出内容

必须提供以下两部分输出：

### 1. 优化后的简历

直接输出优化后的完整简历文本，包括：
- 个人信息
- 教育背景
- 工作经历
- 项目经验
- 技能特长
- 其他内容

### 2. 详细优化建议报告

提供结构化的优化建议，包括：

#### 2.1 整体评估
- 简历整体评分（满分100）
- 优点总结
- 主要问题概述

#### 2.2 逐项优化建议

**个人信息**
- 联系方式是否完整
- 是否有不必要的个人信息
- 照片建议（如有）

**教育背景**
- 学校名称是否需要补充（如：XX大学）
- 学历描述是否清晰
- 是否需要补充绩点/排名（视情况）

**工作经历**
- 公司描述是否清晰
- 工作内容描述是否具体
- 成果是否量化
- 动词使用是否准确
- 时间线是否连续

**项目经验**
- 项目职责是否明确
- 技术栈是否清晰
- 项目成果是否突出
- STAR 法则应用情况

**技能特长**
- 技能分类是否合理
- 熟练程度描述是否准确
- 是否有遗漏的关键技能

#### 2.3 格式建议
- 排版问题
- 字体/字号建议
- 行间距/段落间距
- 内容篇幅建议

#### 2.4 针对性建议
- 根据目标岗位的建议
- 根据用户背景的个性化建议

## 优化原则

### 内容优化原则

1. **具体化**：将模糊描述改为具体描述
   - ❌ "负责项目开发"
   - ✅ "负责用户端产品开发，包括需求分析、技术方案设计、代码实现"

2. **量化成果**：尽可能用数字说话
   - ❌ "提升了系统性能"
   - ✅ "优化后接口响应时间从 500ms 降至 50ms，性能提升 10 倍"

3. **动词开头**：每条经历用强有力的动词开头
   - 使用：负责、主导、推动、优化、提升、实现、开发、设计、构建
   - 避免：参与、协助、学习、了解

4. **突出价值**：强调个人贡献和价值
   - ❌ "团队完成了XX功能"
   - ✅ "独立完成XX功能开发，为公司带来XX收益"

5. **关键词匹配**：适当包含行业/岗位关键词

### 格式优化原则

1. **简洁清晰**：控制篇幅，核心信息一目了然
2. **层次分明**：使用统一的标题层级
3. **对齐统一**：同类信息对齐展示
4. **适当留白**：避免过于拥挤
5. **重点突出**：关键信息加粗或前置

## 注意事项

1. **保护隐私**：不泄露用户简历中的敏感个人信息
2. **尊重原意**：在优化的基础上保留用户的核心表达
3. **务实可行**：建议要具体可执行，避免空泛
4. **一视同仁**：无论用户背景如何，提供专业、认真的服务
5. **适度平衡**：在突出优势和坦诚不足之间找到平衡
